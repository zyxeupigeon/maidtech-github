# 快捷键冲突治理提示词

> 复制给 AI 助手(ZCode/Claude 等)直接执行。环境:1.21.1 Fabric 整合包客户端。
> 来源:130+ 按键绑定的重度整合包实战治理。

====== 提示词开始 ======

帮我治理 Minecraft 客户端的按键冲突,按以下规范执行:

【背景】我的客户端是 1.21.1 Fabric 整合包,按键数量 130+,几乎所有字母键都有绑定,
多个 mod 抢同一个键。已知问题:同键多绑会互相干扰。

【关键环境知识(务必遵守)】
1. 按键配置文件:游戏版本目录下的 options.txt,格式为 key_key.<键名>:<键值>
   (注意前缀是两层 key_);解绑写 key.keyboard.unknown;组合键写 LCTRL+key.keyboard.x 形式
2. 编辑 options.txt 前必须:①确认游戏已完全关闭 ②备份一份
3. 原版 1.21.1 按键系统不支持修饰键组合;只有 masa 系 mod
   (litematica/minihud/tweakeroo)的自家配置界面支持组合键 → 组合键优先在它们那里设置
4. 装有 Keybind Fix Updated(keybind_fix)后,同键多绑可以共存触发,
   所以治理策略 = "解绑废键 + 上下文共存的冲突接受",不是消灭所有重键

【执行步骤】
1. 从 options.txt 提取全部 key_ 行,按键值分组,列出所有"一键多绑"组
2. 对每个冲突组,判断各绑定的使用场景:
   - 全局触发的(如光影重载、截图录制)与高频操作撞键 → 必须挪走或解绑
   - 仅特定上下文触发的(骑乘时、某维度内、持特定物品时)→ 可共存,标注即可
3. 识别"低作用键"并解绑:GIF 录制、截图类热键、一次性的演示键、
   已卸载 mod 的残留条目(选项里还在但 mod 已删的)
4. 输出改动清单表(键位/原绑定/新状态/理由),经我确认后再实际修改

【修改规范】
- 每次修改前备份 options.txt(加日期后缀)
- 修改只动 options.txt 和 mod 配置文件,不动 mod jar
- 完成后列出:释放了哪些键、哪些冲突组保留、为什么
